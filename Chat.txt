**[THỰC THI NGHIỆP VỤ - VÒNG ĐỜI VOUCHER (7 YÊU CẦU NÂNG CAO)]**
Áp dụng quy tắc quản lý vòng đời Voucher theo thời gian thực. Bổ sung trạng thái `2` (Chưa hoạt động) bên cạnh `1` (Hoạt động) và `0` (Ngưng).

**Bước 1: Cập nhật `#VoucherBUS.java`**

1. Trong hàm `isValid(VoucherDTO v)`, sửa dòng `if (v.getTrangThai() != 0 && v.getTrangThai() != 1) v.setTrangThai(1);` thành `if (v.getTrangThai() < 0 || v.getTrangThai() > 2) v.setTrangThai(1);` để cho phép trạng thái số 2.
2. Thêm mới hàm sau vào cuối class để tự động quét trạng thái:
Java

```
public void autoUpdateVoucherStatuses() {
    List<VoucherDTO> list = getAll();
    if (list == null) return;
    java.time.LocalDate now = java.time.LocalDate.now();
    for (VoucherDTO v : list) {
        int currentState = v.getTrangThai();
        int correctState = currentState;
        // Nếu đang ngưng thủ công (0) mà hạn vẫn còn thì kệ nó (không tự bật lên).
        // Nhưng nếu bị sai ngày thì ép tự động:
        if (v.getNgayBatDau() != null && v.getNgayBatDau().isAfter(now)) {
            correctState = 2; // Chưa tới ngày -> Chưa hoạt động
        } else if (v.getNgayKetThuc() != null && v.getNgayKetThuc().isBefore(now)) {
            correctState = 0; // Hết hạn -> Ngưng hoạt động
        } else if (currentState == 2 && v.getNgayBatDau() != null && !v.getNgayBatDau().isAfter(now)) {
            correctState = 1; // Đến ngày -> Kích hoạt
        }
        if (currentState != correctState) {
            v.setTrangThai(correctState);
            updateVoucher(v);
        }
    }
}
```

**Bước 3: Nâng cấp UI trong `#VoucherPanel.java`**

1. Chuyển đổi các ô nhập ngày sang `com.github.lgooddatepicker.components.DatePicker`.
2. Cập nhật `cboTrangThai` có 3 item: `{"Ngưng hoạt động", "Hoạt động", "Chưa hoạt động"}`.
3. Tạo hàm `private void evaluateVoucherState()` để xử lý UI ràng buộc:
Java

```
private void evaluateVoucherState() {
    java.time.LocalDate start = dpNgayBatDau.getDate();
    java.time.LocalDate end = dpNgayKetThuc.getDate();
    java.time.LocalDate now = java.time.LocalDate.now();

    // Luôn cho phép sửa ngày kết thúc
    dpNgayKetThuc.setEnabled(true);

    if (start != null) {
        // Khóa ngày bắt đầu nếu đã qua hoặc bằng hôm nay (Voucher đã chạy)
        if (!isAddingNew && !start.isAfter(now)) {
            dpNgayBatDau.setEnabled(false);
        } else {
            dpNgayBatDau.setEnabled(true);
        }

        if (start.isAfter(now)) {
            // Tương lai -> Bắt buộc Chưa hoạt động, liệt Combobox
            cboTrangThai.setSelectedItem("Chưa hoạt động");
            cboTrangThai.setEnabled(false);
        } else if (end != null && end.isBefore(now)) {
            // Quá khứ -> Bắt buộc Ngưng hoạt động, liệt Combobox
            cboTrangThai.setSelectedItem("Ngưng hoạt động");
            cboTrangThai.setEnabled(false);
        } else {
            // Đang trong hạn (Hiện tại) -> Cho phép Ngưng/Hoạt động thủ công
            cboTrangThai.setEnabled(true);
            if (cboTrangThai.getSelectedItem().equals("Chưa hoạt động")) {
                cboTrangThai.setSelectedItem("Hoạt động");
            }
        }
    }
}
```

*(Ghi chú: Khai báo cờ `private boolean isAddingNew = false;`, gán = true khi bấm nút Thêm, gán = false khi Click bảng).*
4. Gắn listener vào DatePicker để tự gọi `evaluateVoucherState()`:

Java

```
dpNgayBatDau.addDateChangeListener(e -> evaluateVoucherState());
dpNgayKetThuc.addDateChangeListener(e -> evaluateVoucherState());
```
